## ユーザージャーニー

### 1. 認知
- Twitter/X、検索「Slack AI 秘書」でLP到達

### 2. 興味（LP）
- 「月70時間削減」「ROI 70倍」の数値訴求
- ☕/⚡ モードの面白さ
- 30回無料、カード不要 → 心理的障壁ゼロ

### 3. 体験（無料枠）
- 「無料で試す」→ Slack OAuth（Add to Slack）→ 30秒で利用開始
- Bot が自己紹介DMを自動送信（使い方例付き）
- **無料30回**（ノーマルモード）で価値を体験
- Aha Moment: 最初の質問に10秒で的確回答

### 4. 課金の壁
- 31回目 → 「無料枠を使い切りました。プランを選んでください」
- **節約時間を数値表示**: 「これまでに約X時間の作業をお手伝いしました」
- Stripe Checkout（3日間無料トライアル付き）
- Slackボタンで1クリック決済

### 5. 定着
- 週次サマリーDM: 「今週の節約時間: X時間（¥XX,XXX相当）」
- 使ってない日は「こんなこともできますよ」ナッジ

### 6. 拡大
- 1人が使う → チームに「@たすく 使ってみて」と紹介
- ユーザー数増加 → Team/Business プランにアップグレード提案

## 課金モデル

### 2つのモード
| | ☕ ノーマル | ⚡ カフェイン |
|---|---|---|
| モデル | Claude Sonnet | Claude Opus |
| 品質 | 高い（日常業務） | 最高（深い分析・創作） |
| コスト/回 | ¥2.5（原価） | ¥12.5（原価） |
| 使い方 | デフォルト | 「⚡」付きで指定 or 後から切替 |

### 無料枠
- 30回（ノーマルモード）
- 原価: ¥75/ユーザー（Sonnet）
- カード登録不要
- 100人が無料で終わっても ¥7,500 の損失（Solo 1件で回収）

### 原価割れ防止
- Sonnet固定のノーマルモード → 500回使い切っても原価¥1,250（粗利87%）
- Opus は完全従量 → ¥30/回で原価¥12.5（粗利58%）
- 超過ノーマルも従量 → 絶対赤字にならない

### 最悪ケース損益
| プラン | 月額 | ☕全消費+超過200回+⚡100回 | 原価 | 粗利 |
|---|---|---|---|---|

## 技術アーキテクチャ

### コンポーネント
```
[Slack] ←Socket Mode→ [tasuku-bot] ←HTTP API→ [OpenClaw Gateway] → [Anthropic API]
                            ↕                         ↕
                     [Stripe API]              [tenant workspace]
                            ↕                  (SOUL.md, memory/)
                     [tenants.json]
```

### テナント分離
- 1 OpenClaw Gateway = 1 Slack ワークスペース
- ワークスペース内のユーザーは session key で分離
- ~400MB RAM / テナント → gmk で最大50テナント

### 認証
- Slack OAuth（"Add to Slack"）= SSO
- 自前認証なし

### プロビジョニング（自動）
1. Slack OAuth callback → workspace_id 取得
2. create-tenant.sh 実行（ポート自動割当、Gateway起動）
3. tenants.json に登録
4. Bot が自己紹介DM送信

### 課金フロー
1. 無料30回消費 → Stripe Checkout URL 提示
2. ユーザーが決済 → Stripe Webhook
3. Webhook → tenants.json 更新 → 制限解除
4. 月次: Stripe Metered Billing で従量分請求
